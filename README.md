# LS
ls rewrite as an excersize inspired by tonybtw's tutorial on C

## Compilation

``` gcc -Wall -Wextra -o lsbtw ls.c ```

## Functionality 
this program has core ls functionality, u can do long format output or list hidden files, i added alphabethical sorting with ``` quicksort ``` and set width for links and file sizes


``` ./lsbtw -la /a/b/c ```
